# Trabajo Fin de Grado - Grado en Matemáticas - Universidad Complutense de Madrid
 
## Modelos para estimación del valor de glucosa intersticial a partir de variables biométricas en deportistas

Se ha demostrado una clara influencia entre los niveles de glucosa en sangre y la actividad física, especialmente en personas con Diabetes. 
En la actualidad no existen muchos estudios que expliquen si existe relación entre variables fisiológicas derivadas del deporte como el ritmo cardiaco, los pasos, impactos y desplazamientos y la glucosa intersticial. 
En este estudio se investigará la aplicación de técnicas de estadística, optimización e inteligencia artificial para obtener modelos de la relación entre las citadas variables. Para ello se utilizarán chalecos medidores de actividad física y ritmo cardiaco y sensores de glucosa.
